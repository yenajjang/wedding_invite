# Mobile Wedding Invitation

정적 HTML/CSS/JS로 만든 모바일 청첩장입니다. 별도 빌드 과정이 없어 그대로 호스팅할 수 있습니다.

## 로컬 확인
`index.html`을 브라우저에서 열면 됩니다.

## 호스팅
아래 서비스에 `wedding-invite` 폴더 전체를 업로드하면 됩니다.
- GitHub Pages
- Netlify Drop
- Vercel Static
- Cloudflare Pages

## 수정할 곳
- 이름/날짜/장소/문구: `index.html`
- 사진: `assets/` 폴더
- 색상/폰트/레이아웃: `style.css`
